# Bedstead

`bedstead.otf` is Bedstead 3.261, an outline font based on the characters of
the Mullard SAA5050 teletext character generator, by Ben Harris.

- Source: https://bjh21.me.uk/bedstead/
- Licence: CC0 1.0 (SPDX `CC0-1.0`). The author has dedicated the generator
  program and all the newly designed glyphs to the public domain; see
  https://bjh21.me.uk/bedstead/#copyright.

The receiver page (`index.html`) loads it from `GET /receiver/bedstead.otf`
for the teletext screen.
